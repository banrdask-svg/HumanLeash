# HumanLeash

Плагин Paper 1.21.11 / Java 21: поводок между игроками с ограничением расстояния и управлением через команды.

## Установка

Соберите: `gradlew.bat build` на Windows или `sh gradlew build` на Linux. Установите JAR из `build/libs` в `plugins` сервера Paper 1.21.11, перезапустите сервер. Настройки создаются в папке плагина.

## Использование

Нужны OP или право `humanleash.admin`. Введите `/leash`, чтобы увидеть подсказку. Подкоманды: `bind` — привязать, `unbind` — отвязать, `distance` — изменить расстояние, `info` — информация, `reload` — перечитать настройки. Точные аргументы смотрите в подсказках команды и автодополнении. Алиасы: `/hleash`, `/povodok`. Сначала проверьте привязку двух игроков на тестовом сервере.
